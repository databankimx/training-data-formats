# 18. Appendix

This appendix has no new samples and no quizzes. It collects what the earlier chapters taught into three pages you can return to after the tutorial: a cheat sheet of libraries and checks, a guide to choosing a format, and a glossary of the terms the tutorial used.

Each page assumes you have worked through the chapters it refers to. The cheat sheet names the library behind each format in each language, so that code in a lesson and code you write later use the same tools. The format guide compares the formats by what they are good at and where they go wrong. The glossary gives one plain definition for each term, with the chapter where it first appears.

The chapter has three reading steps and nothing to run. Use the search in your own editor, or the chapter list in the runner, to find a term you need.
